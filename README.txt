NOIRE CAFE - ASSESSMENT II

1. Letakkan folder NOIRE_Cafe_Assessment2 di C:\laragon\www\ atau salin isinya ke folder project Assessment 1.
2. Pastikan Apache Laragon aktif.
3. Buka http://localhost/NOIRE_Cafe_Assessment2/
4. Folder files dan images akan digunakan untuk menyimpan upload.

Deskripsi Aplikasi

NOIRÉ Café merupakan aplikasi menu kafe berbasis PHP yang dikembangkan dengan menerapkan konsep Object-Oriented Programming (OOP). Aplikasi ini menampilkan berbagai pilihan menu makanan, bakery, dan minuman.

Pada Assessment II, aplikasi dikembangkan dengan menambahkan fitur PHP Session untuk menyimpan nama pengunjung dan data upload sementara, serta fitur Upload File untuk mengunggah gambar dan dokumen ke folder terpisah.

Kesesuaian dengan Ketentuan Tugas:

- Menerapkan PHP Session untuk menyimpan data sementara pengguna.
- Menyediakan fitur upload gambar ke folder images.
- Menyediakan fitur upload dokumen ke folder files.
- Menerapkan validasi jenis dan ukuran file serta keamanan proses upload.

Demikian pengembangan aplikasi NOIRÉ Café pada Assessment II ini dibuat sebagai penerapan materi PHP Session dan Upload File.
