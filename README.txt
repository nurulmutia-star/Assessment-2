NOIRE CAFE - ASSESSMENT II

1. Letakkan folder NOIRE_Cafe_Assessment2 di C:\laragon\www\ atau salin isinya ke folder project Assessment 1.
2. Pastikan Apache Laragon aktif.
3. Buka http://localhost/NOIRE_Cafe_Assessment2/
4. Folder files dan images akan digunakan untuk menyimpan upload.

Fitur Assessment II:
- PHP Session menyimpan nama pengunjung dan daftar upload sementara per sesi.
- Upload gambar ke folder images (JPG/JPEG/PNG/GIF/WEBP, maksimal 3 MB).
- Upload dokumen ke folder files (PDF/TXT/DOC/DOCX/XLS/XLSX/PPT/PPTX/ZIP, maksimal 5 MB).
- Validasi ekstensi, MIME type, ukuran file, nama file acak, dan CSRF token.

File script.js dipertahankan dari Assessment I. style.css mempertahankan desain NOIRE dan menambahkan tampilan fitur Assessment II.
